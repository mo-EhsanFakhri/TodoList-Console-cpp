
# پروژه Todo List کنسولی با C++

## معرفی پروژه
این پروژه یک برنامه Todo List کنسولی است که به‌عنوان پروژه پایانی درس «برنامه‌سازی پیشرفته»
و با هدف تمرین مفاهیم برنامه‌نویسی شی‌ءگرا (OOP) در زبان C++ پیاده‌سازی شده است.

## اهداف پروژه
- تمرین عملی مفاهیم شی‌ءگرایی در C++
- طراحی کلاس پایه و کلاس‌های مشتق
- پیاده‌سازی یک سیستم مدیریت کارها (Todo List)
- استفاده از ساختارهای داده و قابلیت‌های STL
- طراحی منوی تعاملی در محیط کنسول


## مفاهیم شی‌ءگرایی به‌کار رفته
در این پروژه مفاهیم زیر از مفاهیم زیر استفاده شده است:

- **ارث‌ بری**:  
  کلاس `Todo` از کلاس پایه `Task` ارث‌بری می‌کند.
- **کپسوله‌سازی**:  
  استفاده از سطح دسترسی `private` و `public` برای مدیریت داده‌ها.
- **چندریختی**:  
  استفاده از متدهای `virtual` و بازنویسی آن‌ها در کلاس‌های مشتق.
- **تفکیک مسئولیت کلاس‌ها**:  
  هر کلاس وظیفه مشخصی را بر عهده دارد. 


## قابلیت‌های برنامه
- افزودن کار جدید
- نمایش همه کارها
- نمایش کارهای انجام‌شده و انجام‌نشده
- تغییر وضعیت انجام کار
- حذف کار
- مدیریت اولویت کارها (Low / Medium / High)
- ثبت تاریخ سررسید (Deadline)
- تشخیص و نمایش کارهای عقب‌افتاده
- منوی تعاملی کنسولی
